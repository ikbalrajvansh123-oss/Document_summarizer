# 🧠 Local RAG System

A fully **offline** Retrieval-Augmented Generation (RAG) system that lets you chat with your own `.txt` documents using a **local LLM via LM Studio** (Qwen 3 1.7B by default). No cloud services, no API keys, no internet required after the initial setup.

---

## ✨ Features

- 📄 **Document Ingestion** — Drop `.txt` files into the `uploads/` folder; they are automatically chunked, embedded, and stored in a local vector database (ChromaDB).
- 🔍 **Semantic Search** — Uses `all-MiniLM-L6-v2` sentence embeddings to find the most relevant document chunks for each question.
- 🤖 **Local LLM** — Answers are generated by **Qwen 3 1.7B** running locally inside LM Studio (no data leaves your machine).
- 🛡️ **Hallucination Guard** — A two-stage confidence check (before and after calling the LLM) blocks answers that are not grounded in the retrieved context.
- 📊 **Aggregate Query Mode** — Questions like *"how many employees?"* or *"summarize the document"* automatically read the **entire** document instead of just the top-K chunks.
- 🗂️ **Unanswered Log** — Low-confidence questions are silently logged to `unanswered.json` for review instead of returning a wrong answer.
- 🖥️ **Two UIs** — A **Streamlit** chat interface for interactive use and a **FastAPI** REST API for programmatic access.

## 🚀 Getting Started

### 1. Prerequisites

| Requirement | Notes |
|---|---|
| **Python 3.10+** | Install from [python.org](https://www.python.org/) |
| **LM Studio** | Download from [lmstudio.ai](https://lmstudio.ai/) |
| **Qwen 3 1.7B model** | Load it inside LM Studio |

### 2. Install Dependencies

```bash
pip install -r requirements.txt
```

### 3. Start LM Studio

1. Open **LM Studio** on your machine.
2. Load the **Qwen 3 1.7B** model (or any other compatible model).
3. Start the **Local Server** on `http://127.0.0.1:1234`.

> **Tip:** The model identifier in LM Studio must match the value of `LM_STUDIO_MODEL` in `rag_core.py` (default: `qwen3-1.7b`). If you use a different model, update that constant.

### 4. Add Your Documents

Copy one or more `.txt` files into the `uploads/` folder:

```
uploads/
├── employees.txt
├── report_2024.txt
└── manual.txt
```

### 5. Run the Application

**Option A — Streamlit UI (recommended for interactive use)**

```bash
streamlit run streamlit_app.py
```

Open your browser at **http://localhost:8501**.

**Option B — FastAPI REST API**

```bash
uvicorn app:app --reload
```

Open your browser at **http://localhost:8000** for the built-in HTML UI.  
Interactive API docs are available at **http://localhost:8000/docs**.

## 🧩 How It Works

```
User Question
      │
      ▼
  Is it an aggregate query?
  (how many / list all / summarize)
      │
   YES │                    NO
      ▼                     ▼
  Retrieve ALL chunks    Embed question →
  from the document      Semantic search (top-K chunks)
      │                     │
      └──────────┬───────────┘
                 ▼
         Confidence Check #1
         (Is the subject even mentioned in the context?)
                 │
         Below 75%? → Log to unanswered.json → Return "not found"
                 │
                 ▼
         Send context + question to LM Studio (Qwen 3 1.7B)
                 │
                 ▼
         Confidence Check #2
         (Do the answer's claims exist in the context?)
                 │
         Below 75%? → Log to unanswered.json → Return "not found"
                 │
                 ▼
          Return answer + source chunks
```

## 🌐 REST API Reference

| Method | Endpoint | Description |
|---|---|---|
| `GET` | `/health` | Check server and LM Studio status |
| `GET` | `/files` | List all indexed files |
| `POST` | `/scan-folder` | Re-scan `uploads/` and ingest new `.txt` files |
| `DELETE` | `/files/{file_id}` | Delete a file and all its indexed chunks |
| `POST` | `/query` | Ask a question against the indexed documents |

### `/query` Request Body

```json
{
  "question": "Where does Alice work?",
  "top_k": 4,
  "file_id": null
}
```

- **`question`** *(required)* — The question to answer.
- **`top_k`** *(optional, default: 4)* — Number of chunks to retrieve (similarity search mode only).
- **`file_id`** *(optional)* — Restrict the search to a specific file. Omit to search across all files.

### `/query` Response

```json
{
  "answer": "Alice works at Acme Corp as a Software Engineer.",
  "sources": [
    {
      "filename": "employees.txt",
      "chunk_index": 2,
      "preview": "Alice Johnson — Software Engineer at Acme Corp...",
      "distance": 0.18
    }
  ],
  "mode": "similarity_search",
  "grounded": true,
  "confidence": 1.0
}
```

## ⚙️ Configuration

All configuration constants are at the top of `rag_core.py`:

| Constant | Default | Description |
|---|---|---|
| `LM_STUDIO_URL` | `http://127.0.0.1:1234/v1/chat/completions` | LM Studio API endpoint |
| `LM_STUDIO_MODEL` | `qwen3-1.7b` | Model identifier (must match what is loaded in LM Studio) |
| `EMBED_MODEL_NAME` | `all-MiniLM-L6-v2` | Sentence-transformer embedding model |
| `CHUNK_SIZE_WORDS` | `200` | Maximum words per document chunk |
| `CHUNK_OVERLAP_WORDS` | `40` | Overlap words between consecutive chunks |
| `TOP_K_DEFAULT` | `4` | Default number of chunks retrieved per query |
| `CONFIDENCE_THRESHOLD` | `0.75` | Minimum confidence score to return an answer |

## 🛡️ Hallucination Detection

This system uses a **two-stage grounding check** to avoid returning incorrect answers:

1. **Pre-LLM check** — Extracts the meaningful keywords from the question (e.g., a person's name) and verifies that they appear in the retrieved context. If fewer than 75% of keywords are found, the question is immediately logged as unanswered.

2. **Post-LLM check** — Extracts proper nouns and numbers from the generated answer and verifies each one exists in the source context. If more than 25% of the answer's claims cannot be traced back to the context, the answer is withheld.

Low-confidence questions are appended to **`unanswered.json`** for your review.

## 🔒 Privacy

All processing happens **locally on your machine**:

- Embeddings are generated by a local model (`all-MiniLM-L6-v2`).
- Answers are generated by Qwen 3 1.7B running inside LM Studio.
- No telemetry, no cloud calls, no external APIs.
